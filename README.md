# 📊 Global Data Professional Dashboard | Power BI

## 📌 About the Project
An interactive Power BI dashboard that analyzes survey data from data professionals to explore salary trends, programming language preferences, job roles, education levels, and work-life balance.

## 🎯 Key Features
- Salary comparison by gender and job role
- Programming language preferences
- Country and industry distribution
- Salary satisfaction and work-life balance
- Career entry difficulty analysis
- Education-level salary comparison

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 💡 Objective
To transform survey data into meaningful insights about careers, salaries, and workplace trends in the data industry.
